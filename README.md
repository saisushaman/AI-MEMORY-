# AI-MEMORY

Research project on **long-term memory for LLM agents**, investigating canonical reusable memory units, semantic deduplication, cross-context memory reuse, multi-view memory, and token-budgeted context composition.

## Research question

> Can semantic memory deduplication and cross-context memory reuse reduce both long-term memory redundancy and LLM context-token consumption without degrading task performance?

## Status

**Phase 1 — Literature review (in progress).**
